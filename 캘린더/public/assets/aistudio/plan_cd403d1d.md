# 한송초 3,4학년 일정 공유 캘린더 기획서

## 1. 서비스 개요
- **서비스 제목:** 한송초 3,4학년 일정 공유 캘린더
- **목적:** 교사가 등록한 학교·학년 일정을 한 달 달력으로 공유하고, 날짜를 눌러 시간과 장소 등 상세 정보를 확인한다.
- **주요 사용자:** 일정을 등록하는 교사와 일정을 확인하는 학생·학부모 등 누구나.
- **확정 사항:** 누구나 로그인 없이 열람하며, 3·4학년 일정을 하나의 달력에 함께 표시한다. 별도 로그인 화면은 만들지 않는다.
- **형태:** PC와 모바일에서 이용하는 반응형 웹 서비스.

## 2. 첫 화면
- 화면 상단에 **“한송초 3,4학년 일정 공유 달력에 오신 것을 환영합니다”**를 큰 글씨로 표시한다.
- 그 아래 현재 월의 달력을 첫 화면의 주 콘텐츠로 크게 배치한다.
- PC에서는 환영 문구와 월 이동 영역을 제외한 화면 높이를 달력이 최대한 채우도록 한다.
- 모바일에서는 글자 가독성과 터치 영역을 유지하며 필요하면 세로 스크롤을 허용한다.
- 상단에 현재 연도·월, 이전 달, 다음 달, 오늘 버튼을 배치한다.
- 기본 진입 시 한국 시간 기준 이번 달을 표시하고 오늘 날짜를 강조한다.

## 3. 핵심 사용자 흐름
1. 사용자가 접속하면 이번 달 달력과 등록된 일정이 보인다.
2. 일정이 있는 날짜에는 일정 제목과 개수를 표시한다.
3. 날짜를 클릭하면 해당 날짜의 일정 목록을 팝업으로 표시한다.
4. 팝업에서 각 일정의 구체적인 시간, 장소, 설명을 확인한다.
5. 닫기 버튼, 팝업 바깥 클릭 또는 Esc 키로 팝업을 닫는다.

## 4. 필수 기능(MVP)

### 월간 달력
- 일요일부터 토요일까지 7열로 표시한다.
- 월별 날짜와 요일을 정확하게 계산하고 월 이동을 지원한다.
- 일정이 많은 날짜는 일부 제목과 “+N개”를 표시한다.
- 일정이 없는 날짜를 누르면 “등록된 일정이 없습니다”를 표시한다.
- 로딩 중, 조회 실패, 등록된 일정이 전혀 없는 상태를 구분해서 안내한다.

### 일정 상세 팝업
- 선택한 날짜와 요일을 제목으로 표시한다.
- 같은 날짜의 모든 일정을 시작 시간 순서로 나열한다.
- 각 일정에 제목, 대상 학년, 시작·종료 시간, 장소, 설명을 표시한다.
- 종일 일정은 시간 대신 “종일”을 표시한다.
- 긴 내용은 팝업 안에서 스크롤할 수 있게 한다.
- 팝업에 키보드 초점을 이동하고 닫은 뒤 원래 날짜로 복귀시킨다.

### 교사 일정 관리
- 교사는 일정을 등록·수정·삭제할 수 있다. 별도 로그인은 사용하지 않는다. 일정 등록·수정·삭제 시 교사 공용 편집 비밀번호를 입력해 권한을 확인한다. 공개 열람이 누구나 편집할 수 있다는 의미는 아니다.
- 저장된 일정은 다른 사용자도 새로 조회하면 확인할 수 있도록 서버에 보관한다.
- 필수 입력: 제목, 날짜, 대상 학년, 시간(또는 종일), 장소.
- 선택 입력: 설명.
- 대상 학년: 3학년, 4학년, 3·4학년 공통.
- 제목과 장소의 공백 입력을 막고, 종료 시간이 시작 시간보다 빠르면 저장하지 않는다.
- 삭제 전 확인창을 표시하고 저장 실패 시 입력 내용을 유지한다.
- 읽기·쓰기 권한은 서버에서도 검증한다.

## 5. 데이터 모델 초안
| 필드 | 의미 |
|---|---|
| id | 일정 고유 ID |
| title | 일정 제목 |
| date | 한국 시간 기준 날짜(YYYY-MM-DD) |
| grade | 3, 4, common 중 하나 |
| allDay | 종일 여부 |
| startTime / endTime | 시작·종료 시각, 종일이면 비워 둠 |
| location | 장소 |
| description | 설명 |
| createdBy | 등록자 표시값(선택 입력, 개인 계정 없음) |
| createdAt / updatedAt | 생성·수정 시각 |

초기 버전은 하루 안에 끝나는 일정을 기준으로 한다. 여러 날짜에 걸친 일정과 반복 일정은 별도 요구사항 확인 후 확장한다.

## 6. 디자인 및 접근성
- 밝은 배경과 차분한 색상을 사용해 학교 안내 서비스처럼 친근하고 읽기 쉽게 구성한다.
- 일정은 색상뿐 아니라 텍스트로 학년을 구분한다.
- 날짜와 버튼은 모바일에서도 누르기 쉬운 크기로 만든다.
- 환영 문구는 작은 화면에서 자연스럽게 줄바꿈한다.
- 키보드만으로 날짜 선택, 월 이동, 팝업 열기·닫기가 가능하게 한다.

## 7. 구현 방향 제안
- 프런트엔드: React + TypeScript 기반 반응형 웹.
- 저장소: 공유 데이터베이스를 제공하는 백엔드를 사용한다. 별도 로그인 기능은 구현하지 않으며, 교사 편집 권한은 공용 편집 비밀번호로 확인한다.
- 브라우저 내부 저장만으로 공유 기능을 구현하지 않는다.
- 초기 화면 개발 시 예시 일정을 사용하되 실제 일정과 명확히 구분하고 정식 운영 전 제거한다.
- 열람은 전체 공개로 구현한다. 일정 편집 기능은 공용 편집 비밀번호 검증 후 사용할 수 있게 연결한다.

## 8. 완료 기준
- 첫 화면에 지정한 환영 문구와 이번 달 달력이 크게 표시된다.
- 이전 달·다음 달·오늘 이동이 정상 작동한다.
- 일정이 있는 날짜를 누르면 해당 날짜의 모든 일정과 정확한 시간·장소가 표시된다.
- 교사가 저장한 일정이 다른 사용자의 화면에서도 조회된다.
- 권한 없는 사용자는 일정 등록·수정·삭제를 할 수 없다.
- 빈 일정, 다수 일정, 월 경계, 2월·윤년, 저장 실패를 확인한다.
- PC와 모바일에서 달력과 팝업 내용을 읽고 조작할 수 있다.

## 9. 제작 전 확인할 사항
- **확정:** 누구나 열람 가능, 별도 로그인 없음, 3·4학년 일정 통합 표시.
- **확정된 편집 방식:** 별도 계정 로그인 없이 교사 공용 편집 비밀번호를 사용한다. 비밀번호를 아는 교사는 전체 일정을 등록·수정·삭제할 수 있다. 열람에는 비밀번호가 필요 없다.
1. **일정 범위:** 반복 일정, 여러 날 일정, 공휴일 표시가 초기 버전에 필요한가?
2. **운영 환경:** 학교에서 정해 둔 홈페이지·호스팅·데이터 저장 정책이 있는가?

## 10. 후속 확장 후보
- 학년별 필터, 일정 검색, 반복 일정, 여러 날 일정.
- 일정 변경 알림과 외부 캘린더 구독.
- 인쇄 및 일정 내보내기.

확장 후보는 초기 필수 기능에 포함하지 않는다.


## 11. 공용 편집 비밀번호 구현 기준
- 달력에 “교사 일정 관리” 버튼을 배치하고, 편집 진입 시 공용 비밀번호를 요청한다.
- 올바른 비밀번호를 입력한 경우에만 등록·수정·삭제 기능을 제공한다.
- 비밀번호 검증과 모든 변경 요청의 권한 검사는 서버에서 수행한다.
- 비밀번호를 화면 코드, 공개 저장소 또는 브라우저 저장소에 넣지 않는다. 서버에는 안전한 해시로 보관한다.
- 검증 후에는 만료 시간이 있는 보안 세션을 사용하고 “편집 종료” 버튼으로 종료할 수 있게 한다.
- 잘못된 비밀번호에는 오류를 표시하고 반복 시도 횟수를 제한한다.
- 실제 공용 비밀번호는 운영 설정 단계에서 정하며 기획서에는 기록하지 않는다.
- 검증 항목: 비밀번호 없이 조회 가능, 잘못된 비밀번호로 편집 불가, 올바른 비밀번호로 전체 일정 관리 가능, 세션 만료·종료 후 변경 요청 차단.
